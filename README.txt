# Jain American Impact Network - Static Website

Two-page static site:
- index.html - organization overview, purpose, member organizations and links
- events.html - Jain Diwali on Capitol Hill 2026 event page
- styles.css - responsive styling
- assets/ - organization marks used in the site

The site is intentionally presented as an informal umbrella collaboration rather than a separate tax-exempt legal entity.

Member links:
- JAINA: https://www.jaina.org/
- JITO USA: https://www.jitousa.org/
- JSMW: https://www.jsmw.org/
- IDJO: https://idjo.org/
- JSNOVA: https://jsnova.org/

Note: JAINA and JITO USA identity references were checked against their official sites. The other three marks are simplified web-ready representations for the prototype and should be replaced with the organizations' approved logo files before public launch, subject to permission.
